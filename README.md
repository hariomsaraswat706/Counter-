# Counter Smart contract 

# Description 

This Smart Contract store a Counter value  and allows user to increase and decrease , reset  it ; 

# Functions 
1 : Increase Count ,
2 : Decrease Count , 
3 : Reset Count Zero  ,
4 : Prevent negativ values 

# state variables 
uint public Count = store the current Counter value ; 

# Deploy 
Deployed using Remix ide ;
